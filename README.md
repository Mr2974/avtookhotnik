# Автоохотник CZ

Ищет на **Sauto.cz** и **Bazoš.cz** ликвидные машины, выставленные заметно ниже рынка, с нормальным пробегом.
Работает бесплатно на серверах GitHub: каждые 2 часа запускает поиск, обновляет сайт-ленту
и пишет новые находки в Telegram.

- **Сайт-лента:** `https://<ваш-логин>.github.io/<имя-репозитория>/` — открывается с телефона, ссылкой можно поделиться.
  Языки: русский, English, українська, čeština (переключатель RU / EN / UA / CZ, выбор запоминается).
- **Уведомления:** Telegram-канал или группа, куда пишет ваш бот. Друзей добавляете туда же.

## Как устроен поиск
- Модели: Octavia, Superb, Fabia, Karoq, Kodiaq, Scala, Rapid, Yeti, Kamiq, Golf, Passat, Tiguan, Touran, Polo,
  Corolla, Auris, Yaris, RAV4, i30, Tucson, ix35, Ceed, Sportage, Focus, Duster, CX-5 (список в `config.json`).
- **Рынок** — медиана цен похожих объявлений Sauto: та же модель и поколение, год ±1, близкий пробег,
  тот же двигатель, топливо и КПП. Спортивные версии (RS, GTI, ST…) сравниваются только между собой.
- **Находка** — дешевле рынка на 30 % и больше, или на 12 % и больше, если продавец пишет
  «rychlé jednání», «při rychlém jednání sleva», «potřebuji prodat», «dohoda možná», «rodinné auto», «dědictví» и т. п.
  Эти фразы дополнительно ищутся полнотекстом по всему рынку.
- **Проверка описания** (`defects.py`, бесплатно): бот читает полное описание КАЖДОЙ машины до того, как она попадёт в ленту,
  и ищет то, что продавец сам пишет о неисправностях (без учёта отрицаний «nic neteče», «bez koroze» и уже сделанного ремонта
  «nové těsnění pod hlavou»):
  - **критично — машина не публикуется**: не на ходу, на díly / na opravu, závada motoru или převodovky, těsnění pod hlavou,
    přehřívání, po povodni, havarované, bez TP, cena jen při financování, leasing;
  - **серьёзно — предупреждение и минус к оценке**: уходит chladicí kapalina / antifriz, течёт или ест масло, дымит, spojka,
    setrvačník, turbo, DPF, vstřikovače, svítí kontrolka, электрика, ходовая, koroze, bez STK, nutná oprava, сомнительный пробег;
  - **мелочи — пометка**: ťukance, škrábance, prasklé sklo, pneu, opotřebený interiér, klimatizace.
  На карточке видна цитата продавца, на которую сработала проверка. Скидки больше 60 % тоже отсеиваются (почти всегда обман).
- **ИИ-проверка фото и описания** (`ai_check.py`, необязательно, платно по факту): Claude смотрит до 5 фото и описание каждой
  новой машины и даёт оценку внешнего вида 1–5 (вмятины, ржавчина, следы аварии, перекрашенные детали, трещины, салон,
  горящие контрольки на приборке), вердикт и короткое резюме на 4 языках. Машины с вердиктом «отсеять» убираются из ленты.
  Включается, только если в репозитории есть секрет `ANTHROPIC_API_KEY` (ключ API с console.anthropic.com — отдельная оплата
  по факту использования, не подписка Claude). Модель и лимит — `ai_model`, `ai_effort`, `ai_photos`, `ai_max_per_run`
  в `config.json`. Ориентир по цене: `claude-opus-5-5` ≈ 0,05 $ за машину; `claude-haiku-5-5` ≈ 0,001 $ (дешевле в ~40 раз,
  чуть менее внимательна). Сколько потрачено за поиск, пишется в журнале запуска (строка «ИИ-проверка»).
- **Реальная цена продажи и чистая выручка** (блок «Реально продать» на сайте и в Telegram):
  1. **По продажам.** Бот запоминает все объявления Sauto (~33 тыс.) и замечает исчезнувшие — проданные машины.
     Последняя цена такого объявления и сколько дней оно провисело — реальные данные «за сколько и как быстро уходит».
     Берутся продажи за 1–60 дней, минус ~3 % торга. Включается, когда для похожих машин накопилось 5+ продаж
     (для популярных моделей — через 1–3 дня работы, дальше точность растёт). История хранится в ветке `history`.
  2. **По частникам**, пока продаж мало: объявления частных продавцов Sauto + Bazoš (дилерские цены завышены):
     «быстро» = нижняя четверть цен − 3 %, «обычно» = медиана − 5 % на торг.
  3. **Грубая оценка**, если данных совсем мало (рынок × 0,82–0,88) — помечается на карточке.
  Чистая выручка = цена продажи − цена покупки − расходы (`resale_costs`, 6 000 Kč: переоформление, STK/emise, мойка, объявление).
  **Facebook Marketplace не используется:** он закрыт входом в аккаунт и защитой от автоматического сбора, его правила такой сбор
  запрещают. Цены частников на Facebook в Чехии обычно близки к Bazoš.
- У каждой машины: VIN (если есть) и ссылка на официальную проверку пробега Министерства транспорта ЧР
  (kontrolatachometru.cz, там нужно ввести капчу), готовое сообщение продавцу на чешском, оценка маржи при перепродаже.

## Запуск (один раз, ~10 минут)
1. **Репозиторий.** Залейте эти файлы в **публичный** репозиторий GitHub (у публичных репозиториев Actions бесплатны без лимита).
2. **Сайт.** Settings → Pages → Build and deployment: *Deploy from a branch*, ветка `main`, папка `/docs` → Save.
   Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.
3. **Telegram-бот** (необязательно, но удобно):
   1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя → получите **токен** (вида `123456:ABC...`).
   2. Создайте **канал** (или группу), добавьте бота администратором.
      Для публичного канала ID — его адрес, например `@avto_pod_rynkom`.
      Для закрытой группы: напишите в неё любое сообщение и откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` —
      там будет `"chat":{"id":-100...}`.
   3. В репозитории: Settings → Secrets and variables → Actions → **New repository secret**:
      `TELEGRAM_BOT_TOKEN` = токен, `TELEGRAM_CHAT_ID` = ID канала.
   4. (Необязательно) вкладка **Variables** → `TELEGRAM_INVITE` = ссылка-приглашение в канал — на сайте появится кнопка «Уведомления в Telegram».
4. **Первый запуск.** Actions → «Поиск машин ниже рынка» → **Run workflow**. Через ~10 минут обновится сайт и придёт сообщение.
   Дальше всё работает само каждые 2 часа.

## Настройка
Всё в `config.json` (правится прямо на GitHub через карандаш):
`price_min` / `price_max` — бюджет в Kč, `year_min`, `km_max`, `min_discount` (0.30 = 30 % ниже рынка),
`models` — список моделей, `sauto_phrases` / `bazos_phrases` — горячие фразы.
Частота — строка `cron` в `.github/workflows/scan.yml`.

## Важно
- Цены — запрашиваемые, не цены сделок. Перед покупкой: VIN, история пробега, осмотр на месте.
- GitHub запускает расписание с задержками и иногда пропускает запуски. Поэтому попытка делается
  каждые 15 минут, а шаг «Пора ли искать» пропускает её ночью (0–6 по Праге) и если с прошлого поиска прошло меньше 100 минут.
  Ручной запуск (Run workflow) ищет всегда; галочка «report» — прислать отчёт в Telegram, даже если нового нет.
- GitHub отключает расписание, если в публичном репозитории 60 дней не было активности. Бот сам делает коммиты
  с находками, так что обычно этого не происходит; если всё же отключилось — Actions → Enable workflow.
- Запуск вручную без GitHub: `python3 car_hunter.py --out out && python3 update_site.py` (нужен только Python 3).
